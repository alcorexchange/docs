---
title: "Adding Token Information"
description: "Add your token's description, links and tags through a GitHub pull request"
---

Any project can add information about its token — name, website, socials, tags and description — with a pull request to the [alcor-ui repository](https://github.com/alcorexchange/alcor-ui). Alcor shows it on the token's analytics page (`/v/<network>/analytics/tokens/<token id>`). To add a logo, see [Token logo](/adding-token-information/token-logo).

## Where to add it

Token information lives in [`assets/fundamentals`](https://github.com/alcorexchange/alcor-ui/tree/master/assets/fundamentals), one file per network:

| Network | File |
|---|---|
| WAX | `wax.json` |
| XPR Network | `proton.json` |
| Vaulta (EOS) | `eos.json` |
| Telos | `telos.json` |

## Format

Each file is one JSON object (not an array). Each key is a token id in the form `SYMBOL@contract`, and its value describes the token:

```json
"FWW@farmerstoken": {
  "name": "Farmers World",
  "website": {
    "link": "https://farmersworld.io/",
    "name": "farmersworld.io"
  },
  "tags": ["Gaming", "P2E", "NFT"],
  "socials": [
    "https://t.me/farmersworldofficial",
    "https://twitter.com/FarmersWorldNFT",
    "https://discord.com/invite/V2pdyGdB9V"
  ],
  "github": "https://github.com/shivsriv/FarmersWorld",
  "description": "FarmersWorld is the first farming game to function on the NFTs platform."
}
```

<Callout type="info">
The symbol must be upper case, and the file must stay valid JSON after your change.
</Callout>
