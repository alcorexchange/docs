## Pull request to alcor-ui (recommended)

Add the logo to the [alcor-ui repository](https://github.com/alcorexchange/alcor-ui) with a pull request:

* Folder: `assets/tokens/<network>/`, where `<network>` is `wax`, `proton` (XPR Network), `eos` (Vaulta) or `telos`.
* File name: `<symbol>_<contract>.png`, both in lower case, joined by an underscore — for example `assets/tokens/wax/tlm_alien.worlds.png`.
* Format: a square PNG image.

You can add the token's description and links in the same pull request, see [Adding Token Information](/adding-token-information).

## Other sources

If a token has no logo in alcor-ui, Alcor falls back to:

* on XPR Network, the logo registered in the network's own token registry (`token.proton`);
* the [eos-airdrops](https://github.com/eoscafe/eos-airdrops) repository. Adding a token there takes a pull request to that repository; this [video tutorial](https://www.youtube.com/watch?v=pL68Llsr9pA) walks through it.
