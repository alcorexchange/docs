---
title: "Alcor Price Oracle vs DelphiOracle"
description: "How the Alcor TWAP oracle differs from DelphiOracle."
---

DelphiOracle is an oracle contract on Antelope chains. Block producers fetch prices from centralized exchanges and write them on-chain, and the contract publishes the latest values for a small set of pairs. The Alcor Price Oracle is computed from trading in Alcor Swap pools.

| | Alcor Price Oracle | DelphiOracle |
| --- | --- | --- |
| Data source | Trades in Alcor Swap pools, on-chain | Prices from centralized exchanges, written by block producers |
| Price type | Time-weighted average over any window, or spot | Latest reported price |
| History | As many observations as the pool keeps; can be extended by paying for RAM | Recent values only |
| Pairs | Every Alcor Swap pool | A few major pairs, such as WAX/USD |
| Freshness | Lags the market during fast moves, by design of the averaging window | Follows external markets, updated as producers report |
| Manipulation | Requires holding the pool price off-market for the whole window; safer with deep liquidity and a longer window | Requires compromising the reporting producers |
| Cost to extend | RAM for extra observations | None for users |
