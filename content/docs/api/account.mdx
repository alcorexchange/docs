History and positions of one account on the chain of the host you call.

## Spot trades

Spot trades the account took part in, as buyer or seller, newest first.

`GET https://wax.alcor.exchange/api/v2/account/<account>/deals`

**Parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| account | string | yes | Account name, in the path |
| market | number | no | Only trades of this spot market id |
| from | number | no | Range start, unix seconds. Used only together with `to` |
| to | number | no | Range end, unix seconds |
| limit | number | no | Number of trades. Default `500` |
| skip | number | no | Trades to skip, for paging |

**Example**

```shell
curl "https://wax.alcor.exchange/api/v2/account/alcordexfund/deals?limit=1"
```

```json
[
  {
    "_id": "6ac07c9e48ec8ec3f10389bc",
    "market": 26,
    "type": "buymatch",
    "trx_id": "4cbcefed8b0608063fb2001bfc3527e7eee19bfa8c612a3df882524f42177e81",
    "unit_price": 0.2699,
    "ask": 1148.4228,
    "bid": 309.95930066,
    "asker": "jjrbg.wam",
    "bidder": "alcordexfund",
    "time": "2026-10-03T03:55:10.500Z"
  }
]
```

**Response fields**

| Name | Type | Description |
| --- | --- | --- |
| _id | string | Trade id |
| market | number | Spot market id |
| type | string | `buymatch`: a buy order took the trade. `sellmatch`: a sell order took it |
| trx_id | string | Transaction id |
| unit_price | number | Trade price |
| bidder | string | Account of the order that took the trade |
| asker | string | Account of the resting order it matched |
| bid | number | Amount the bidder paid |
| ask | number | Amount the bidder received |
| time | string | Trade time, ISO 8601 |

## Positions

Open AMM liquidity positions of the account, with their value and fees.

`GET https://wax.alcor.exchange/api/v2/account/<account>/positions`

**Example**

curl https://wax.alcor.exchange/api/v2/account/alcordexfund/positions

## Position history

Liquidity events of the account's positions (deposits, withdrawals and fee collections), newest first.

`GET https://wax.alcor.exchange/api/v2/account/<account>/positions-history`

**Parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| account | string | yes | Account name, in the path |
| limit | number | no | Number of events. Default `200` |
| skip | number | no | Events to skip, for paging |

**Example**

```shell
curl "https://wax.alcor.exchange/api/v2/account/alcordexfund/positions-history?limit=1"
```

```json
[
  {
    "_id": "6acdedec428d9e14968e17b8",
    "id": 152287,
    "pool": 12397,
    "owner": "alcordexfund",
    "type": "burn",
    "tokenA": 918.880068,
    "tokenB": 1077.024205,
    "tokenAUSDPrice": 1,
    "tokenBUSDPrice": 1,
    "totalUSDValue": 1995.9043,
    "trx_id": "6fb2c3280f4cbdc1f5d799ca67916c89ab1ebde126af808d96f766addde1c75a",
    "time": "2026-10-13T08:38:04.000Z"
  }
]
```

**Response fields**

| Name | Type | Description |
| --- | --- | --- |
| _id | string | Record id |
| id | number | Position id |
| pool | number | Pool id |
| owner | string | Position owner |
| type | string | `mint` (liquidity added), `burn` (liquidity removed) or `collect` (fees collected) |
| tokenA, tokenB | number | Token amounts of the event |
| tokenAUSDPrice, tokenBUSDPrice | number | USD prices of the tokens at the time |
| totalUSDValue | number | Event value, USD |
| trx_id | string | Transaction id |
| time | string | Event time, ISO 8601 |

## Swap history

AMM swaps the account sent or received, newest first.

`GET https://wax.alcor.exchange/api/v2/account/<account>/swap-history`

**Parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| account | string | yes | Account name, in the path |
| limit | number | no | Number of swaps. Default `200` |
| skip | number | no | Swaps to skip, for paging |

**Example**

```shell
curl "https://wax.alcor.exchange/api/v2/account/alcordexfund/swap-history?limit=1"
```

```json
[
  {
    "_id": "6acd57da428d9e14961928bf",
    "pool": 12501,
    "trx_id": "71d2fced1fe31e5b4219e4abe79a2cc4a4161a0ae8ea87dc9b73901b39a85195",
    "sender": "alcordexfund",
    "sqrtPriceX64": "138046174607188499",
    "totalUSDVolume": 5.5362025,
    "tokenA": 1000,
    "tokenB": -5.600885,
    "time": "2026-10-12T21:57:41.000Z"
  }
]
```

The fields are those of [Pool swaps](/api/swap#pool-swaps).
