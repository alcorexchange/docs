The Alcor API serves the data of the AMM and the order books on every chain Alcor runs: tokens and their USD
prices, pools with their live state, liquidity positions, markets, candles, analytics, farms, staking, OTC and
account history, plus a stream of live events. It is read-only and needs no key. Swapping and placing orders are
blockchain transactions, signed by the user and sent to a node (see [Swap route](/api/swap-route) and
[Trade API](/api/trade-api)).

## Base URL

One host for every chain. The chain is the first segment of the path:

```
https://api.alcor.exchange/<chain>/...
```

| Chain | `<chain>` | Example |
| --- | --- | --- |
| WAX | `wax` | `https://api.alcor.exchange/wax/pools` |
| Vaulta (EOS) | `eos` | `https://api.alcor.exchange/eos/pools` |
| Telos | `telos` | `https://api.alcor.exchange/telos/pools` |
| XPR Network | `xpr` | `https://api.alcor.exchange/xpr/pools` |

`GET https://api.alcor.exchange/chains` lists the chains. XPR is `xpr` here, not `proton` as in the
[legacy API](/api/legacy).

```bash
curl https://api.alcor.exchange/wax/tokens/tlm-alien.worlds/price
```

```json
{
  "chain": "wax",
  "tokenId": "tlm-alien.worlds",
  "price_usd": 0.000938,
  "source": "derived",
  "via_pool": 0,
  "updated_at": "2026-11-23T15:36:53.677Z"
}
```

## Conventions

* **Token id**: `<symbol>-<contract>` with the symbol in lower case, e.g. `tlm-alien.worlds`. Any contract can issue
  any symbol, so the contract is part of the id.
* **Amounts**: fields named `*_raw` or `*_amount` are integers in the token's smallest units, as strings: divide by
  `10^decimals`. Amounts in a position's `state` are the exception: they are already decimal.
* **Big integers**: int64 values (block numbers, counters) are strings.
* **Time**: responses carry ISO 8601 UTC strings. The `from`, `to` and `before` query parameters take unix
  milliseconds.
* **Paging**: lists take `limit` with `page`, `offset` or a cursor (`before`, `cursor`), as each endpoint states.
* **Errors**: `{"error": "<message>"}` in JSON. HTTP 400 for an invalid parameter, with the details in `issues`;
  HTTP 404 when the thing does not exist.
* **Rate limits**: requests are limited per IP address; over the limit the API answers HTTP 429. For a higher limit
  for a bot or an integration, write to the [Alcor Telegram](/social-media-contact).

| Area | Endpoints |
| --- | --- |
| Tokens | `/<chain>/tokens`, `tokens/<id>`, `tokens/<id>/price`, `tokens/<id>/holders`, `tokens/<id>/logo` |
| AMM pools | `/<chain>/pools`, `pools/<id>`, `pools/<id>/stats`, `pools/<id>/trades`, `pools/<id>/positions`, `pools/<id>/liquidity`, `pools/<id>/activity` |
| Positions | `/<chain>/positions/<id>`, `positions/<id>/events` |

| Order book markets | `/<chain>/markets`, `markets/<id>` |
| Candles | `/<chain>/charts/amm/<poolId>`, `charts/pair?base=&quote=`, `charts/orderbook/<marketId>` |
| Analytics | `/<chain>/analytics/overview`, `charts`, `tokens`, `pools`, `markets`, `lp-leaderboard` |
| Farms | `/<chain>/farms`, `farms/<id>`, `farms/<id>/events` |
| Staking (liquid.alcor) | `/<chain>/staking/system`, `staking/withdraws` |
| OTC | `/<chain>/otc/orders`, `otc/orders/<id>`, `otc/history`, `otc/tokens` |
| Meme terminal | `/<chain>/launchpad/tokens`, `launchpad/token/<id>/summary`, `trades`, `holders` |
| Search | `/<chain>/search?q=` |
| Live events | `/<chain>/events?channels=` |

Parameters and response fields of each are in the [reference](https://api.alcor.exchange/docs).

## Live events

`GET /<chain>/events?channels=<channel>,<channel>` is a stream of
[Server-Sent Events](https://developer.mozilla.org/docs/Web/API/Server-sent_events): one connection, any number of
channels. A browser reads it with `EventSource`; no client library is needed.

| Channel | Events |
| --- | --- |
| `pool:<poolId>` | Swaps, position and farm actions on the pool, its new state |
| `pools:all` | `pool.updated` of every pool, at most once per pool per block |
| `account:<name>` | The account's swaps, transfers, balance changes, position, farm and staking actions |
| `token:<tokenId>` | Transfers, balance changes and USD price changes of the token |
| `tokens:all` | `tokens.prices`: the prices that changed in each pricing pass |
| `position:<positionId>` | Actions on the position |
| `incentive:<incentiveId>` | Farm actions on the incentive |
| `book:<marketId>` | Fills on the order book market and the price levels that changed |
| `launchpad:all` | The meme terminal's cards that changed |
| `staking:all` | Every liquid.alcor staking action |

```javascript
const events = new EventSource('https://api.alcor.exchange/wax/events?channels=pool:1252,tokens:all')

events.addEventListener('swap', e => console.log('swap', JSON.parse(e.data)))
events.addEventListener('tokens.prices', e => console.log('prices', JSON.parse(e.data).prices))
```

Each message is `event: <type>` and `data: <JSON>`; the schema of every event type is under components in the
[reference](https://api.alcor.exchange/docs).

## Legacy API

The old API on each chain's host (`https://wax.alcor.exchange/api/...`, versions v1, v2 and v3) is deprecated. It
still answers, but gets no new features and will be switched off. [Legacy API](/api/legacy) lists what replaces
each old endpoint.

## Contracts

Writing to Alcor means calling its contracts through any node API, with a library such as
[Wharf](https://wharfkit.com) or [eosjs](https://github.com/EOSIO/eosjs).

| Chain | Spot DEX | AMM |
| --- | --- | --- |
| WAX | `alcordexmain` | `swap.alcor` |
| EOS | `eostokensdex` | `swap.alcor` |
| Telos | `eostokensdex` | `swap.alcor` |
| XPR Network | `alcor` | `swap.alcor` |

Contract actions and tables are described in [Developers](/developers-api).
