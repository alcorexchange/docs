---

Alcor Swap is a concentrated-liquidity AMM on the `swap.alcor` contract. These endpoints read its pools and positions
and find swap routes.

<Callout type="info">

How the AMM works: [Alcor Swap](/alcor-swap/introduction) and the [AMM swap contract API](/developers-api/amm-swap-contract-api).
To compute prices, positions and routes locally, without the API, use the
[Alcor Swap SDK](https://github.com/alcorexchange/alcor-v2-sdk).

</Callout>

## Pools

All AMM pools, including inactive ones.

`GET https://wax.alcor.exchange/api/v2/swap/pools`

**Parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| tokenA | string | no | Only pools with this token as token A. With `tokenB`, the pools of that pair in either order |
| tokenB | string | no | Only pools with this token as token B |
| hide_scam | boolean | no | `true` leaves out pools with a token on the scam lists |

**Example**

```shell
curl "https://wax.alcor.exchange/api/v2/swap/pools?tokenA=wax-eosio.token&tokenB=usdt-usdt.alcor"
```

Answers an array of pools, as in [Pool](#pool).

## Pool swaps

Swaps of a pool, newest first.

`GET https://wax.alcor.exchange/api/v2/swap/pools/<pool_id>/swaps`

**Parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| pool_id | number | yes | Pool id, in the path |
| from | number | no | Only swaps at or after this time, unix milliseconds |
| to | number | no | Only swaps at or before this time, unix milliseconds |
| sender | string | no | Only swaps sent by this account |
| recipient | string | no | Only swaps received by this account |
| limit | number | no | Number of swaps. Default `200` |
| skip | number | no | Swaps to skip, for paging |

**Example**

```shell
curl "https://wax.alcor.exchange/api/v2/swap/pools/1095/swaps?limit=1"
```

```json
[
  {
    "_id": "6ad0bded29945be352deacb2",
    "pool": 1095,
    "trx_id": "096bbefb42fe7e43580c68d05c02b95682b5c722b1fd01fb90fadf29e0abb90e",
    "sender": "eldrinvale12",
    "recipient": "eldrinvale12",
    "sqrtPriceX64": "12931342024590619",
    "totalUSDVolume": 0.4345,
    "tokenA": -87.80659353,
    "tokenB": 0.4325,
    "time": "2026-10-15T11:50:05.000Z"
  }
]
```

**Response fields**

| Name | Type | Description |
| --- | --- | --- |
| _id | string | Record id |
| pool | number | Pool id |
| trx_id | string | Transaction id |
| sender | string | Account that sent the swap |
| recipient | string | Account that received the output |
| sqrtPriceX64 | string | Pool price after the swap, Q64.64 square root |
| totalUSDVolume | number | Swap value, USD |
| tokenA, tokenB | number | Token amounts, signed from the pool's side: positive went into the pool, negative came out |
| time | string | Swap time, ISO 8601 |

## Pool candles

OHLCV candles of a pool, oldest first. Periods without swaps are filled with flat candles at the last price.

`GET https://wax.alcor.exchange/api/v2/swap/pools/<pool_id>/candles`

**Parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| pool_id | number | yes | Pool id, in the path |
| resolution | string | yes | Candle size: `1`, `5`, `15`, `30`, `60`, `240` (minutes), `1D`, `1W`, `1M` |
| from | number | no | Start time, unix milliseconds. Used together with `to` |
| to | number | no | End time, unix milliseconds |
| limit | number | no | Most candles to return |
| reverse | boolean | no | `true` gives prices of token B in token A. Default: token A in token B |
| volumeField | string | no | `volumeUSD` (default), `volumeA` or `volumeB` |

**Example**

```shell
curl "https://wax.alcor.exchange/api/v2/swap/pools/1095/candles?resolution=60&from=1792057410000&to=1792068210000"
```

```json
[
  { "time": 1792058400000, "open": "0.00489139", "high": "0.00493338", "low": "0.00488846", "close": "0.00489139", "volume": 3.6053 },
  { "time": 1792062000000, "open": "0.00489139", "high": "0.00491414", "low": "0.00489288", "close": "0.00491414", "volume": 1.4758 }
]
```

**Response fields**

| Name | Type | Description |
| --- | --- | --- |
| time | number | Candle start, unix milliseconds |
| open, high, low, close | string | Prices |
| volume | number | Volume in the unit chosen by `volumeField` |

To get candles by token pair rather than by pool, use
`GET https://wax.alcor.exchange/api/v2/swap/candles?tokenA=<token_id>&tokenB=<token_id>` with the same parameters. It
picks the pair's main pool (the active pool with the highest TVL), prices token A in token B as asked, and answers
`{ "candles": [...], "poolId": 1095, "isReversed": false }`, where `isReversed` tells that the pool holds the tokens in
the other order.

## Swap route

The best way to swap one token for another through the AMM pools, ready to be sent as transfers to `swap.alcor`.

`GET https://wax.alcor.exchange/api/v2/swapRouter/getRoute`

**Parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| trade_type | string | yes | `EXACT_INPUT`: `amount` is what you send. `EXACT_OUTPUT`: `amount` is what you receive |
| input | string | yes | Token id you send |
| output | string | yes | Token id you receive |
| amount | string | yes | Amount in token units, e.g. `1.5`. No more decimals than the token has |
| slippage | number | no | Tolerance in percent. Default `0.3` |
| receiver | string | no | Account written into the memos. Default is the literal `<receiver>`, to replace before signing |
| maxHops | number | no | Most pools per route. Default and maximum `3` |
| v2 | any | no | Any non-empty value splits the trade across up to 5 routes. Without it, one route |
| includePoolDetails | boolean | no | `true` adds `pools`: fee and tokens of every pool used |

**Example**

```shell
curl "https://wax.alcor.exchange/api/v2/swapRouter/getRoute?trade_type=EXACT_INPUT&input=wax-eosio.token&output=tlm-alien.worlds&amount=10&slippage=0.3&receiver=alcordexfund&maxHops=2"
```

```json
{
  "route": [12501, 12406],
  "memo": "swapexactin#12501,12406#alcordexfund#39.7961 TLM@alien.worlds#0",
  "swaps": [
    {
      "input": "10.00000000 WAX",
      "route": [12501, 12406],
      "output": "39.9155 TLM",
      "percent": 100,
      "memo": "swapexactin#12501,12406#alcordexfund#39.7961 TLM@alien.worlds#0",
      "maxSent": "10.00000000",
      "minReceived": "39.7961"
    }
  ],
  "input": "10.00000000",
  "output": "39.9155",
  "minReceived": "39.7961",
  "maxSent": "10.00000000",
  "priceImpact": "0.31",
  "executionPrice": { "numerator": "399155", "denominator": "1000000000" }
}
```

**Response fields**

| Name | Type | Description |
| --- | --- | --- |
| swaps | array | One transfer per split, see below |
| input | string | Total amount sent |
| output | string | Total amount expected |
| minReceived | string | Exact input: the least the trade may return, after slippage |
| maxSent | string | Exact output: the most the trade may take, after slippage |
| priceImpact | string | Percent below the pools' spot prices |
| executionPrice | object | Raw output per raw input, as a fraction |
| route, memo | array, string | Pools and memo of the first swap only. Kept for old clients; use `swaps` |
| pools | object | Only with `includePoolDetails=true`: pool id to `fee`, `tokenA`, `tokenB` |

**Each swap**

| Name | Type | Description |
| --- | --- | --- |
| input | string | Asset to transfer |
| output | string | Asset this swap is expected to return |
| percent | number | Share of the trade |
| route | array | Pool ids the swap goes through |
| memo | string | Memo for the transfer |
| minReceived, maxSent | string | This swap's bounds |

To swap, put one `transfer` of the input token per element of `swaps` into a single transaction: `to: "swap.alcor"`,
`quantity: swap.input`, `memo: swap.memo` with `<receiver>` replaced by the user's account.

Errors are plain text: HTTP 403 with `Invalid request`, `Invalid amount`, `Invalid slippage` or `Invalid input/output`,
and HTTP 404 with `No trading route available. Try again in a few moments.`

## Swap route v3

Routes through the AMM pools and the spot order books together. Answers with the transfers to send and, given the
user's account, the actions ready to sign. Use it for new integrations.

`GET https://wax.alcor.exchange/api/v3/swapRouter/getRoute`

**Parameters**

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| tradeType | string | yes | `exactIn`: `amount` is what you send. `exactOut`: `amount` is what you receive (AMM only) |
| input | string | yes | Token id you send |
| output | string | yes | Token id you receive |
| amount | string | yes | Amount in token units, e.g. `1.5` |
| slippage | number | no | Tolerance in percent. Default `0.3` |
| account | string | no | The user's account: receiver of every swap and signer of `actions`. Without it the memos carry `<account>` and there are no `actions` |
| permission | string | no | Permission for `actions`. Default `active` |
| maxHops | number | no | Pools per AMM route, `1` to `3`. Default `3` |
| orderbook | boolean | no | `false` keeps the trade on the AMM. Default `true` |

**Example**

```shell
curl "https://wax.alcor.exchange/api/v3/swapRouter/getRoute?tradeType=exactIn&input=wax-eosio.token&output=tlm-alien.worlds&amount=10&slippage=0.3&account=alcordexfund"
```

```json
{
  "tradeType": "exactIn",
  "input": { "id": "wax-eosio.token", "symbol": "WAX", "contract": "eosio.token", "decimals": 8, "amount": "10.00000000" },
  "output": { "id": "tlm-alien.worlds", "symbol": "TLM", "contract": "alien.worlds", "decimals": 4, "amount": "39.9242" },
  "minReceived": "39.8047",
  "maxSent": "10.00000000",
  "priceImpact": "0.3",
  "routes": [
    {
      "percent": 61,
      "input": "6.10000000",
      "output": "24.3483",
      "hops": [
        { "venue": "amm", "pool": 12501, "input": "wax-eosio.token", "output": "usdt-wrap.alcor", "fee": "0.01" },
        { "venue": "amm", "pool": 12406, "input": "usdt-wrap.alcor", "output": "tlm-alien.worlds", "fee": "0.3" }
      ]
    }
  ],
  "transfers": [
    {
      "tokenContract": "eosio.token",
      "to": "swap.alcor",
      "quantity": "6.10000000 WAX",
      "memo": "swapexactin#12501,12406#alcordexfund#24.2754 TLM@alien.worlds#0"
    }
  ],
  "actions": [
    {
      "account": "eosio.token",
      "name": "transfer",
      "authorization": [{ "actor": "alcordexfund", "permission": "active" }],
      "data": {
        "from": "alcordexfund",
        "to": "swap.alcor",
        "quantity": "6.10000000 WAX",
        "memo": "swapexactin#12501,12406#alcordexfund#24.2754 TLM@alien.worlds#0"
      }
    }
  ]
}
```

**Response fields**

| Name | Type | Description |
| --- | --- | --- |
| tradeType | string | As requested |
| input, output | object | Token metadata and the total `amount` sent or expected |
| minReceived | string | Exact input: the least the trade may return |
| maxSent | string | Exact output: the most the trade may take |
| priceImpact | string | Percent below the venues' spot prices |
| routes | array | Paths the input takes: `percent`, `input`, `output` and `hops`. Each hop has `venue` (`amm` or `orderbook`), `pool` or `market`, `input` and `output` token ids, `fee` in percent |
| transfers | array | What to send, in order: `tokenContract`, `to`, `quantity`, `memo` |
| actions | array | Only with `account`: the transfers as actions, ready to sign |

Sign `actions` as they are, in order, in one transaction. An AMM leg is a transfer to `swap.alcor`. An order book leg is
a transfer to the DEX contract with the memo `<minimum> SYM@contract|min`: a market order that reverts the whole
transaction if it pays less than the minimum.

Errors are JSON, `{"error": "<message>"}`: HTTP 400 for a bad parameter (`Invalid tradeType`, `Unknown token`,
`Invalid amount`, `Invalid slippage`, `Invalid maxHops`, `Invalid orderbook`, `Input and output are the same token`),
HTTP 404 for `No route`.
