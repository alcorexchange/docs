Markets, orders and pools live on chain. You can trade, cancel orders and read tables with a block explorer, `cleos` or a JavaScript client such as eosjs. For HTTP and WebSocket data, see the [API Reference](/api).

## Contract accounts

| Chain | Order book DEX | Swap (AMM) |
| --- | --- | --- |
| WAX | `alcordexmain` | `swap.alcor` |
| EOS | `eostokensdex` | `swap.alcor` |
| Telos | `eostokensdex` | `swap.alcor` |
| XPR Network (Proton) | `alcor` | `swap.alcor` |

The first-generation AMM contract `alcorammswap` still holds old liquidity on WAX and Telos. See [Legacy AMM pairs](/developers-api/contract-tables#legacy-amm-pairs).
