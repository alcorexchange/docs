You are building a project on Telos, WAX, XPR Network or Vaulta, or bringing users there from other chains.
Find what you need below, open its guide, and start from the runnable example. Hand this page and
[alcor-examples](https://github.com/alcorexchange/alcor-examples) to your AI agent: its
[AGENTS.md](https://github.com/alcorexchange/alcor-examples/blob/main/AGENTS.md) has the rules that keep your
users' money safe.

## For AI agents

- Start from [alcor-examples](https://github.com/alcorexchange/alcor-examples): small runnable scripts, one per task,
  and [AGENTS.md](https://github.com/alcorexchange/alcor-examples/blob/main/AGENTS.md) with the rules.
- The whole site as text for a model: [llms.txt](/llms.txt) (an index) and [llms-full.txt](/llms-full.txt)
  (every page).
- Wallet and sign-in: [Alcor Signer for AI agents](/alcor-signer/for-agents).
- The Alcor API describes itself: [reference](https://api.alcor.exchange/docs),
  [OpenAPI](https://api.alcor.exchange/docs/json). The API on each chain's host (`<chain>.alcor.exchange/api/...`) is
  [deprecated](/api/legacy): do not build on it.
- The bridge API describes itself: [reference](https://telos.alcor.exchange/api/bridge/docs),
  [signing on every chain](https://telos.alcor.exchange/api/bridge/docs/bot),
  [OpenAPI](https://telos.alcor.exchange/api/bridge/openapi.yaml). Prefer them over memory.
- Never move money without the user's explicit yes, for that amount, address and network.
