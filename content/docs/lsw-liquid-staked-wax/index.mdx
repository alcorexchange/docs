LSW is Alcor's liquid staking token for WAX. You stake WAX and receive LSW in return. The staked WAX earns WAX staking rewards, which are added back to the stake, so each LSW is redeemable for a growing amount of WAX. Meanwhile LSW itself is a normal token you can trade, provide as liquidity or use elsewhere.

Stake and unstake at `alcor.exchange/v/wax/staking`. LSW exists only on WAX.

| | |
| --- | --- |
| Staking contract | `liquid.alcor` |
| LSW token contract | `lsw.alcor` (symbol `LSW`, 8 decimals) |

## Why use LSW

- **Liquidity**: you earn staking rewards and can still sell, swap or use LSW at any time, instead of waiting out WAX's 3-day unstaking period.
- **No upkeep**: the rewards are claimed and restaked for you; you do not need to vote or claim yourself.
- **Composability**: LSW can be used in Alcor Swap pools and farms, and by other applications that accept it.
