Alcor runs at [alcor.exchange](https://alcor.exchange). Everything can be browsed without a wallet; connecting one enables trading.

## Networks

Pick a network with the network switcher in the header. Each network has its own set of pages under `/v/<network>/`:

| Network | URL prefix |
|---|---|
| WAX | `/v/wax/` |
| XPR Network | `/v/xpr/` |
| Vaulta (formerly EOS) | `/v/vaulta/` |
| Telos | `/v/telos/` |

## Home page

The home page (`/`) is a cross-chain swap: pick any token on any network and any token on another, and Alcor plans the route — a swap on one network, a bridge crossing, or a swap, a crossing and a swap at the far end — signed once on the network where it starts. It also lists trending tokens and top markets on every network.

## Pages on each network

| Page | URL | What it is |
|---|---|---|
| [Swap](/main-page-overview/swap) | `/v/<network>/swap` | Swap two tokens on one network at the best price across pools and order books |
| Pool | `/v/<network>/swap/positions` | Your concentrated-liquidity positions; create, add to, remove and claim fees |
| [Farms](/alcor-farms-unlocking-defi-opportunities) | `/v/<network>/swap/farms` | Stake liquidity positions for extra rewards |
| [Spot](/main-page-overview/spot) | `/v/<network>/spot` | On-chain order book with limit and market orders |
| Terminal | `/v/<network>/terminal` | Token screener: trending, new tokens, holders, live trades |
| Bridge | `/v/<network>/bridge` | Move assets between Ethereum, BNB Smart Chain, Polygon and the Antelope networks |
| Analytics | `/v/<network>/analytics` | TVL, volume and fees, with a page for every pool and token |
| [Portfolio](/main-page-overview/portfolio) | `/v/<network>/portfolio` | Your balances, orders, positions and resources |
| [OTC](/main-page-overview/otc) | `/v/<network>/otc` | Peer-to-peer trades at a fixed price |
| [Stake](/lsw-liquid-staked-wax) | `/v/wax/staking` | WAX liquid staking (WAX only) |

## Connecting a wallet

Use **Connect Wallet** (or **Log in**) in the header and choose a wallet supported on the selected network. On networks where Alcor can create accounts, the same dialog offers to create one if you do not have an account yet.
