## \*This is not financial advice\*

The charting software Alcor Exchange uses is provided by TradingView which is an extremely flexible trading software. There is an infinite amount of information to convey and this slide is intended to provide only the basics. 

For more information about how the chart works and its features visit [www.tradingview.com](/main-page-overview/markets/market-exchange/www.tradingview.com)

![](https://1106702801-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-MJILKtslrmNIVV9CYCR%2F-MgBhY3BmWrya07lTF03%2F-MgBizmwZ3_Gp_wwhnQ_%2Fimage.png?alt=media\&token=f8997f2a-549b-48d0-9288-734ff30fb855)

**Orange Box** - Shows the token pair of the chart you are viewing.

**Green Box** - Toggle the time period each candle represents.

**Purple Box** - A list of different technical indicators to overlay on the chart. 

**Red Box** - List of tools to manually add your own indicators.

**Yellow Box** - Price indicator of the current token pair you are viewing.

**Pink Box** - Shows relative volume at the time of each candle.

**Blue Arrows** - Various chart information based on your settings.
