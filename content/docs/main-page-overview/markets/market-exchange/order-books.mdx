## The order books allow you to see all of the orders people have placed at different prices.

![TLM/WAX Order Book](https://1106702801-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-MJILKtslrmNIVV9CYCR%2F-MgBalYAQq4ABVrpvu_J%2F-MgBhWQU9dv0haTr283f%2Fimage.png?alt=media\&token=7299f12c-3ff5-4a1e-b041-a57210cdc872)

**Blue Box** - Shows the exchange price all the current limit orders are set at.

**Red Box** - The top red numbers are the orders other people have set to sell.

**Green Box** - The bottom green numbers show all of the orders other people have set to buy.

**Pink Boxes** - Shows how much of each token (and that tokens exchange rate) that is being bought and sold at each price.
