Try it on [Alcor Bridge UI](https://alcor.exchange/bridge)!

WAX Network support USDT token, using [IBC technology](https://ibc-docs.uxnetwork.io/). Original USDT are bridged to WAX using **ibc.alcor** bridge contract. and **usdt.alcor** contract for WAX wrapped USDT token. IBC is a secure, decentralized, audited cryptographic protocol that allows you to transfer tokens without having to trust any party.
