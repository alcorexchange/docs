---

The swap widget is a compact Alcor swap form you can embed in any web page. Use the link for your network:

| Network | Widget URL |
|---|---|
| WAX | `https://wax.alcor.exchange/swap-widget` |
| XPR Network | `https://proton.alcor.exchange/swap-widget` |
| Vaulta (EOS) | `https://eos.alcor.exchange/swap-widget` |
| Telos | `https://telos.alcor.exchange/swap-widget` |

Insert it into your page with an iframe:

```html
<iframe src="https://wax.alcor.exchange/swap-widget" width="445" height="600"></iframe>
```

## Query parameters

Token ids use the `symbol-contract` format, for example `wax-eosio.token`.

| Parameter | Meaning | Example |
|---|---|---|
| `input` | Token selected to pay with | `wax-eosio.token` |
| `output` | Token selected to receive | `tlm-alien.worlds` |
| `only` | Comma-separated list of tokens offered in the token selector | `wax-eosio.token,tlm-alien.worlds` |
| `market` | Your registered market account, to earn a fee on swaps made through the widget — see [Referral / Custom Market Fee](/alcor-swap/referral-custom-market-fee) | `mymarket` |

For example:

```html
<iframe
  src="https://wax.alcor.exchange/swap-widget?input=wax-eosio.token&output=tlm-alien.worlds"
  width="445"
  height="600"
></iframe>
```

A price chart for a pair is available as a separate widget, see [Swap Chart Widget](/swap-widget/swap-chart-widget).
