---
title: "Swap Chart Widget"
description: "Embed the price chart of a swap pair"
---

The chart widget shows the price chart of a token pair. It lives at `/chart-widget` on the same hosts as the [Swap Widget](/swap-widget), for example `https://wax.alcor.exchange/chart-widget`.

Required query parameters, as token ids in `symbol-contract` format:

* `input` — the input token
* `output` — the output token

Example:

```html
<iframe
  src="https://wax.alcor.exchange/chart-widget?input=wax-eosio.token&output=tlm-alien.worlds"
  width="600"
  height="400"
></iframe>
```
