Alcor Exchange is a decentralized, self-custodial exchange running since 2020. It started as the order book DEX of WAX and now runs the same stack on four Antelope networks:

* **WAX**
* **XPR Network** (formerly Proton)
* **Vaulta** (formerly EOS)
* **Telos**

The Alcor Bridge connects these networks with each other and with Ethereum, BNB Smart Chain and Polygon, so USDT, USDC and other bridged assets can move between all of them.

## What you can do on Alcor

* **Cross-chain swap** — swap any token on one network for any token on another in one signature, from the home page at [alcor.exchange](https://alcor.exchange).
* **Swap** — best-price swaps on one network, routed through AMM pools and order books together.
* **Pools** — provide concentrated liquidity (Uniswap v3 style) in pools with fee tiers of 0.01%, 0.05%, 0.3% and 1%.
* **Farms** — stake liquidity positions in incentives to earn extra token rewards.
* **Spot** — on-chain order book with limit and market orders.
* **Terminal** — token screener with trending and new tokens, holders and live trades.
* **Bridge** — move assets between Ethereum, BNB Smart Chain, Polygon and the Antelope networks.
* **Portfolio** — balances, open orders, liquidity positions and account resources.
* **Analytics** — TVL, volume and fees per network, pool and token.
* **Liquid staking** — stake WAX for LSW (WAX only).
* **OTC** — peer-to-peer trades at a fixed price.

Every product can be browsed without a wallet; connecting a wallet enables trading. See the [App Overview](/main-page-overview) for where each product lives.

## No whitelisting

Anyone can list a token on Alcor by creating a liquidity pool for it — no approval is needed. Projects can add their logo and description through GitHub, see [Adding Token Information](/adding-token-information).
